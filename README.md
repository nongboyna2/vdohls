# VOD Website

A Video on Demand (VOD) website built with Node.js, Express, MongoDB, and Backblaze B2.

## Features
- User Authentication (Login/Register)
- Video Upload and Management
- Subtitle Support
- VAST Popup Ads using Fluid Player
- Responsive UI
